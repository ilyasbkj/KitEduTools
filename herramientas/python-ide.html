Python IDE en el navegador

Un entorno de práctica para ejecutar ejemplos de Python y aprender mediante pruebas pequeñas y observables.

Aprende por iteraciones

Empieza con un objetivo corto: mostrar un valor, recorrer una lista o escribir una función. Ejecuta el código con frecuencia y lee el mensaje de error completo. Cambiar una parte cada vez permite relacionar el resultado con una decisión concreta.

Uso responsable

No ejecutes código que no entiendas ni intentes acceder a sistemas, credenciales o datos de terceros. Para proyectos importantes, usa control de versiones y pruebas fuera del navegador. El entorno está pensado para aprendizaje, no para almacenar secretos.

Editor HTML

Un espacio de práctica para escribir HTML, CSS y JavaScript y observar el resultado durante el aprendizaje.

Un método de prueba útil

Empieza por una estructura semántica: encabezados, párrafos, listas y enlaces. Después añade estilos y, por último, comportamiento. Cambiar una cosa cada vez hace más sencillo localizar un error y entender qué propiedad produce cada efecto.

Buenas prácticas

Usa títulos en orden, texto alternativo en las imágenes y controles que se puedan usar con teclado. No pegues claves, datos personales ni código de terceras personas sin comprenderlo o tener permiso para usarlo.
